Fitur Interaktif

Fitur Utama WebGIS

WebGIS ini dilengkapi dengan berbagai fitur interaktif yang mendukung kebutuhan analisis tata ruang, diseminasi informasi, dan pengelolaan data spasial secara efisien.

🗺️

Peta Interaktif Multi-Basemap

Tampilan peta interaktif dengan pilihan basemap: OpenStreetMap, Google Maps (Satellite, Hybrid, Terrain), dan ESRI. Navigasi intuitif dengan zoom, pan, dan rotasi peta.

Leaflet.js
🔍

Query & Identifikasi Zona

Klik pada area di peta untuk mendapatkan informasi lengkap zona tata ruang (NAMOBJ), termasuk ketentuan peraturan zonasi yang berlaku berdasarkan Perda Kab. Bogor No. 1/2024.

Popup Interaktif
✏️

Digitasi & Delineasi AOI

Tools untuk menggambar polygon Area of Interest (AOI) secara langsung di peta. Mendukung pembuatan polygon bebas, persegi, dan lingkaran. Data digitasi tersimpan otomatis di localStorage.

Leaflet Draw
⭕

Analisis Buffer

Buat zona buffer dengan radius yang dapat dikustomisasi (dalam meter) dari polygon AOI yang telah didigitasi. Hasil buffer divisualisasikan langsung di peta dengan overlay transparan.

Turf.js
📐

Pengukuran Jarak & Luas

Tool pengukuran interaktif untuk menghitung jarak antar titik dan luas area di peta secara real-time. Hasil ditampilkan dalam satuan meter, kilometer, dan hektar.

Leaflet Measure
🔎

Pencarian Lokasi & Atribut

Fitur pencarian lokasi menggunakan geocoding (Leaflet Photon/Nominatim) dan pencarian atribut dalam layer yang sedang aktif. Hasil pencarian langsung di-zoom ke lokasi terkait.

Geocoding
📍

Deteksi Lokasi Pengguna (GPS)

Tombol lokasi saya (GPS) untuk menemukan dan menampilkan posisi pengguna saat ini di peta, dilengkapi lingkaran akurasi yang menunjukkan radius ketidakpastian posisi GPS.

Geolocation API
🔖

Bookmark View Peta

Simpan posisi dan zoom level peta saat ini sebagai bookmark untuk akses cepat nanti. Maksimal 6 bookmark tersimpan per sesi, dikelola dari panel Ruang Kendali.

LocalStorage
🔄

Swipe Peta (Layer Comparison)

Fitur swipe interaktif untuk membandingkan dua layer peta secara berdampingan dengan slider yang dapat digeser. Berguna untuk melihat perbedaan kondisi lahan antar layer.

Leaflet Swipe
📊

Dashboard Statistik

Dashboard real-time yang menampilkan statistik jumlah fitur tiap layer, status aktif/nonaktif layer, total objek spasial, dan ringkasan operasional data spasial yang tersedia.

Statistik Real-time
🏙️

Dashboard Kecamatan

Halaman dashboard khusus menampilkan statistik detail per kecamatan: luas wilayah, jumlah desa, komposisi pola ruang, dan data demografi dasar. Mendukung 40 kecamatan Kab. Bogor.

Dashboard Kecamatan
🎭

Mode Presentasi

Mode layar penuh yang menyembunyikan semua panel UI (sidebar, layer manager, smart panel) agar peta tampil maksimal untuk keperluan presentasi atau demokrasi publik.

Full Screen Mode
📱

QR Code Akses Lokasi

Generate QR Code otomatis dari koordinat yang sedang ditampilkan di peta. QR Code dapat dipindai untuk membuka posisi peta yang sama di perangkat lain atau dibagikan ke publik.

QRCode.js
🗺️

Peta Mini (Mini Map)

Panel mini map di pojok bawah yang menampilkan gambaran area yang lebih luas sebagai referensi orientasi. Dapat ditampilkan atau disembunyikan sesuai kebutuhan pengguna.

Leaflet MiniMap
🧭

Ruang Kendali (Smart Panel)

Panel insight spasial cepat yang menampilkan status layer aktif, zoom level, koordinat tengah peta, layer prioritas, dan bookmark. Dapat diminimalkan saat tidak dibutuhkan.

Smart Dashboard
🌡️

Indeks Kerawanan Lokasi

Perhitungan otomatis skor risiko (0–100) berdasarkan irisan AOI dengan layer sensitif: KRB, LP2B, LSD, Sempadan, KKOP, Danau, dan Sungai. Kategorisasi: Rendah, Sedang, Tinggi.

Risk Scoring

Analisis Spasial

Fitur Analisis Tata Ruang

Inti dari WebGIS ini adalah kemampuan analisis proporsi lahan yang menghitung irisan antara AOI yang didigitasi pengguna dengan seluruh layer data spasial yang aktif.

Cara Kerja Analisis: Pengguna mendigitasi atau mengimpor polygon AOI → Sistem menghitung luas irisan (intersect) antara AOI dengan setiap layer aktif menggunakan Turf.js → Hasil ditampilkan dalam laporan proporsi lahan lengkap dengan persentase dan ketentuan zonasi.
📏

Analisis Proporsi Lahan

Hitung secara otomatis luas dan persentase irisan area AOI dengan setiap zona tata ruang yang aktif. Hasil disajikan dalam tabel terurut dengan total luasan delineasi.

Intersect Analysis
🏔️

Identifikasi Kawasan Lindung

Deteksi otomatis apakah AOI beririsan dengan kawasan lindung: LP2B, KP2B, LSD, LBS, Sempadan, KKOP, Kawasan Rawan Bencana, Danau, dan Sungai.

Overlay Analysis
📋

Ketentuan Peraturan Zonasi

Tampilkan ketentuan peraturan zonasi lengkap (KPZ) dari file Excel "Ketentuan Peraturan Zonasi.xlsx" untuk setiap zona yang ditemukan dalam AOI, termasuk kategori A/B/C/D kegiatan yang diizinkan.

SheetJS XLSX
🌡️

Skor Risiko Lokasi

Kalkulasi indeks kerawanan lokasi berdasarkan bobot irisan dengan layer sensitif. KRB (+45), LP2B (+25), LSD (+25), Sempadan (+20), KP2B (+20), KKOP (+15), Danau (+15), Sungai (+15).

Manajemen Data

Import & Export Data

WebGIS mendukung berbagai format pertukaran data geospasial, memudahkan integrasi dengan perangkat lunak GIS lain seperti QGIS, ArcGIS, dan Google Earth.

📥

Import GeoJSON / KML / Shapefile

Impor data spasial dari file GeoJSON, KML, atau Shapefile (.zip) langsung ke peta. Data yang diimpor dapat digunakan sebagai AOI untuk analisis proporsi lahan.

webgis-geo-import-export.js
📤

Export Laporan ke PDF

Ekspor laporan analisis spasial lengkap ke format PDF menggunakan html2pdf.js. Laporan mencakup header instansi, total luasan, tabel analisis per zona, dan ketentuan zonasi.

html2pdf.js
📊

Export Laporan ke Excel

Ekspor hasil analisis ke format Excel (.xlsx) dengan multi-sheet: Sheet 1 berisi ringkasan analisis, sheet berikutnya berisi detail ketentuan peraturan zonasi per zona yang ditemukan.

SheetJS XLSX
🖨️

Cetak Peta (Print Layout)

Fitur cetak peta dengan layout profesional, termasuk judul, legenda, skala, arah utara, dan metadata instansi. Tersedia dalam format A4 Portrait dan Landscape.

webgis-print-layout.js

Panduan Penggunaan

Alur Kerja Analisis Tata Ruang

Berikut adalah langkah-langkah standar penggunaan WebGIS DPTR untuk melakukan analisis proporsi lahan dan menyusun laporan spasial.

1

Login & Pilih Basemap

Masuk ke sistem menggunakan akun yang telah didaftarkan. Pilih basemap yang sesuai (OSM, Satellite, atau Google Maps) sesuai kebutuhan analisis.

2

Aktifkan Layer yang Dibutuhkan

Dari panel Layer Manager, centang layer yang akan dianalisis. Layer utama yang disarankan: Pola Ruang (RTRW), LP2B, LSD, KRB, dan Sempadan. Layer dimuat progresif sesuai viewport.

3

Navigasi & Eksplorasi Peta

Navigasi ke lokasi yang akan dikaji. Gunakan fitur pencarian lokasi atau ketikkan koordinat langsung. Klik area di peta untuk melihat informasi zona tata ruang secara langsung.

4

Digitasi atau Import AOI

Gunakan tool digitasi untuk menggambar Area of Interest (AOI) di peta, atau impor file GeoJSON/KML/Shapefile yang sudah disiapkan sebelumnya. AOI harus berupa polygon tertutup.

5

Jalankan Analisis Proporsi Lahan

Tekan tombol "Analisis" untuk menghitung irisan AOI dengan semua layer aktif. Sistem akan menampilkan tabel proporsi lahan per zona tata ruang beserta persentasenya.

6

Tinjau Ketentuan Peraturan Zonasi

Untuk setiap zona yang ditemukan, sistem otomatis menampilkan Ketentuan Peraturan Zonasi (KPZ) dari Excel berdasarkan Perda No.1/2024. Periksa kegiatan yang diizinkan (A/B/C/D).

7

Ekspor Laporan

Unduh laporan dalam format PDF (untuk arsip formal) atau Excel (untuk pengolahan lanjutan). Gunakan juga fitur cetak peta untuk menghasilkan layout peta siap cetak.

Arsitektur Teknis

Komponen Teknologi

WebGIS dibangun di atas tumpukan teknologi open-source yang andal, memenuhi standar OGC (Open Geospatial Consortium) untuk interoperabilitas data spasial.

🌐

Frontend: Leaflet.js

Library JavaScript pemetaan utama. Mendukung WMS, WFS, GeoJSON, marker clustering, measure tools, draw tools, dan berbagai plugin ekosistem Leaflet.

JavaScript
🖥️

GeoServer

Server GIS open-source untuk mempublikasikan data spasial dari PostgreSQL/PostGIS sebagai layanan standar OGC: WMS, WFS, dan WCS. Dioptimalkan dengan GeoWebCache untuk tile caching.

OGC Standard
🐘

PostgreSQL + PostGIS

Database relasional PostgreSQL dengan ekstensi PostGIS sebagai backend penyimpanan data spasial. Semua layer geometri disimpan dan dikelola di database ini.

Spatial Database
📐

Turf.js

Library analisis spasial JavaScript untuk operasi geometri di browser: intersect, buffer, area, length, booleanContains, dan simplify. Seluruh analisis berjalan di client-side.

Client-side GIS
📋

SheetJS (XLSX)

Library untuk membaca file Excel (.xlsx) langsung di browser. Digunakan untuk memuat Ketentuan Peraturan Zonasi dan mengekspor laporan analisis ke format Excel multi-sheet.

Excel Processing
⚡

BBOX-based Progressive Loading

Strategi pemuatan layer yang hanya mengambil data dari GeoServer sesuai area yang terlihat di viewport (BBOX). Dilengkapi tile-grid cache, retry otomatis, dan AbortController.
